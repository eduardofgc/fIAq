Cadeia de Seletividade, Componentes Curriculares e Estrutura Curricular na UnB
Cadeia de Seletividade (ou Cadeia Seletiva): é um grupo de componentes optativos dentro de uma estrutura curricular, do qual o(a) estudante escolhe livremente quais componentes cursar até cumprir a carga horária exigida por aquela cadeia. Nem todos os cursos têm cadeia de seletividade — é preciso consultar a estrutura curricular do próprio curso para saber. Para consultar quais componentes formam uma cadeia de seletividade, acesse o Portal do Discente/SIGAA: Ensino → Consultas Gerais → Consultar Estrutura Curricular, busque seu curso e sua estrutura (o código da estrutura aparece no histórico escolar, no campo "Currículo") — as cadeias de seletividade aparecem no final do relatório da estrutura curricular. As cadeias de seletividade são de cumprimento obrigatório para se formar: ter cursado carga horária optativa além do exigido não dispensa o cumprimento de todas as cadeias de seletividade do curso. Para checar pendências, use a tabela "Componentes Curriculares Obrigatórios Pendentes" do histórico escolar.

Componente Eletivo (antigo "Módulo Livre"): são disciplinas fora da estrutura curricular do curso, mas que qualquer estudante da UnB pode cursar. É possível cursar até 900 horas nessa modalidade, mas só 360 horas são integralizadas (contam para a formatura) — o excedente fica registrado no histórico, mas não conta para conclusão do curso. Cursar componentes eletivos nunca é obrigatório para se formar. A carga horária eletiva é somada automaticamente ao total de carga horária optativa no histórico, sem separação — para saber quanto foi cursado especificamente em eletivas, é preciso somar manualmente os componentes marcados com "#" na legenda do histórico escolar emitido pelo SIGAA.

Componentes Optativos: não existe um mínimo de horas optativas exigido na UnB de forma geral — cada curso define sua própria exigência na estrutura curricular. Para se formar, os três requisitos gerais são: cursar com aprovação todos os componentes obrigatórios do curso; cumprir a carga horária total mínima exigida pelo curso; e, se o curso exigir, estar em situação regular quanto ao ENADE.

Equivalência de Disciplinas: ver documento específico sobre aproveitamento de estudos e equivalência de disciplinas.

Como descobrir em qual estrutura curricular você está: consulte o código no campo "Currículo" do seu histórico escolar, depois acesse o Portal do Discente/SIGAA: Ensino → Consultas Gerais → Consultar Estrutura Curricular, informe o curso e busque — aparecem as estruturas ativas para o curso, e é possível abrir o "Relatório da Estrutura Curricular" completo.
